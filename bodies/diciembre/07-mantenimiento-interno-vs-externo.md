## Introducción

Una de las decisiones más estratégicas que enfrenta un laboratorio analítico es cómo gestionar el mantenimiento de sus equipos: ¿contratar a un técnico interno o externalizar el servicio con un proveedor especializado? Ambas opciones tienen ventajas y desventajas que van más allá del simple costo operativo.

Este artículo presenta un análisis comparativo completo —incluyendo costos directos e indirectos, tiempos de respuesta, capacidades técnicas y cumplimiento normativo— para ayudar a los laboratorios a tomar la mejor decisión según su tamaño, parque analítico y necesidades de servicio.

## Modelo de análisis de costo total

### Escenario típico para un laboratorio mediano (5 equipos: 2 HPLC, 2 GC, 1 FTIR)

| Concepto | Mantenimiento interno (anual) | Contrato externo (anual) |
|----------|------------------------------|-------------------------|
| Salario técnico (1 FTE) | $360,000 MXN | — |
| Capacitación anual | $50,000 MXN | Incluida |
| Herramientas y equipo | $30,000 MXN | Incluido |
| Refacciones (costo + markup) | $120,000 MXN | $100,000 MXN |
| Software de diagnóstico | $25,000 MXN | Incluido |
| Contrato de servicio (preventivo + correctivo) | — | $280,000 MXN |
| Tiempo muerto por espera de refacciones | 5-15 días hábiles/año | 1-3 días hábiles/año |
| **Costo total directo** | **$585,000 MXN** | **$380,000 MXN** |

> El contrato externo resulta **35% más económico** en este escenario, sin considerar los costos indirectos del tiempo muerto.

## Comparación detallada

### Ventajas del mantenimiento interno

| Aspecto | Beneficio |
|---------|-----------|
| Tiempo de respuesta inmediato | El técnico está en el laboratorio, sin tiempo de desplazamiento |
| Conocimiento específico del equipo | Conoce el historial de cada equipo y las fallas recurrentes |
| Flexibilidad | Puede atender emergencias fuera del horario laboral sin costo extra |
| Confidencialidad | Ideal para laboratorios con procesos sensibles o propietarios |
| Inversión a largo plazo | Si el parque analítico es grande (> 10 equipos), el ROI mejora |

### Ventajas del contrato externo

| Aspecto | Beneficio |
|---------|-----------|
| Experiencia multimarca | El proveedor externo conoce múltiples marcas (Agilent, Waters, Shimadzu, Thermo) |
| Inventario de refacciones | Acceso inmediato a refacciones sin inversión en inventario propio |
| Documentación normativa | Reportes de servicio formales para auditorías FDA/EMA/COFEPRIS |
| Actualización continua | Técnicos capacitados en las últimas tecnologías sin costo adicional |
| Continuidad operativa | No depende de la rotación de un solo empleado |

## Análisis por tipo de laboratorio

### Laboratorio pequeño (1-3 equipos)

**Recomendación:** Contrato externo exclusivamente.

| Factor | Justificación |
|--------|--------------|
| Costo | El salario de un técnico interno duplica el costo del contrato |
| Complejidad | Pocos equipos no justifican una FTE dedicada |
| Cobertura | Un contrato con 2 visitas preventivas + correctivo ilimitado es suficiente |
| **Costo estimado** | **$120,000 - $180,000 MXN/año** |

### Laboratorio mediano (4-8 equipos)

**Recomendación:** Contrato externo + un técnico de mantenimiento ligero interno.

| Modelo híbrido | Descripción |
|----------------|-------------|
| Técnico interno nivel 1 | Cambio de consumibles, diagnóstico básico, mantenimiento diario |
| Contrato externo nivel 2-3 | Preventivo mayor, correctivos complejos, calificación IQ/OQ |
| **Costo estimado** | **$450,000 - $550,000 MXN/año** |

### Laboratorio grande (9+ equipos)

**Recomendación:** Equipo interno de mantenimiento + contrato externo para respaldo.

| Factor | Justificación |
|--------|--------------|
| Equipo interno | 1-2 técnicos full-time para preventivo y correctivo menor |
| Contrato externo | Correctivo mayor, refacciones de alto costo, calificación IQ/OQ/PQ |
| Refacciones | Inventario interno de consumibles + catálogo externo para refacciones |
| **Costo estimado** | **$800,000 - $1,200,000 MXN/año** |

## SLA (Service Level Agreement) — Qué negociar

Independientemente de la opción elegida, el SLA debe definir claramente:

| Parámetro | Recomendación para México |
|-----------|--------------------------|
| Tiempo de respuesta telefónica | < 2 horas hábiles |
| Tiempo de llegada a sitio | < 24 horas hábiles (CDMX/área metropolitana); < 48 horas (interior) |
| Tiempo de resolución | < 5 días hábiles (con refacciones en inventario) |
| Penalización por incumplimiento | 5-10% de descuento por día extra |
| Cobertura geográfica | Verificar disponibilidad en el estado/ciudad del laboratorio |
| Refacciones | Porcentaje de refacciones cubiertas vs cargo extra |

## Impacto en auditorías y cumplimiento normativo

### Para laboratorios regulados (FDA, EMA, COFEPRIS)

| Aspecto | Interno | Externo |
|---------|---------|---------|
| Documentación | Requiere que el técnico genere reportes formalmente | El proveedor entrega reportes con formato validado |
| Capacitación documentada | El laboratorio debe mantener registros de capacitación | El proveedor entrega certificados de capacitación |
| Trazabilidad de refacciones | El laboratorio debe gestionar las hojas de seguridad y certificados | El proveedor entrega documentación completa |
| Calificación | IQ/OQ requiere personal calificado con protocolos | El proveedor tiene protocolos validados IQ/OQ/PQ |

> Para laboratorios con acreditación ISO/IEC 17025 o certificación FDA, el contrato externo generalmente simplifica la trazabilidad documental.

## Conclusión

No existe una respuesta única sobre si conviene más el mantenimiento interno o externo. La decisión depende del tamaño del laboratorio, la cantidad de equipos, el nivel de regulación y el presupuesto disponible. El modelo híbrido —técnico interno para el día a día y contrato externo para mantenimiento mayor— suele ser la opción más equilibrada para laboratorios medianos y grandes.
